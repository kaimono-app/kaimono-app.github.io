Assistance

Une question, un bug, une idée ? Écrivez-nous à contact.kaimono.app@gmail.com. Réponse sous quelques jours.

Inviter quelqu’un dans votre espace

Menu ⋯, puis « Inviter quelqu’un ». Envoyez le lien par message : la personne l’ouvre sur son iPhone et rejoint votre liste, sans créer de compte. Si le lien ne s’ouvre pas, elle peut saisir le code de l’espace : au premier lancement (« J’ai un code d’invitation »), ou dans Réglages › Rejoindre un espace avec un code si elle utilise déjà kaimono.

Changer de téléphone sans perdre la liste

Réglages, puis « Sauvegarder avec Apple » ou « Sauvegarder avec un e-mail ». Sur le nouveau téléphone, touchez « Continuer avec Apple » ou « Continuer avec un e-mail » avec le même identifiant : vous retrouvez votre espace.

Supprimer mon compte et mes données

Réglages, puis « Supprimer mon compte ». Vous pouvez d’abord exporter vos données depuis le même écran.
